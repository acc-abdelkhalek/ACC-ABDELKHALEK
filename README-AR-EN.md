# Abdelkhalek Mohamed — Personal Portfolio

A responsive, bilingual (English/Arabic) personal portfolio website for GitHub Pages.

## Included files

- `index.html` — all portfolio content and page structure
- `styles.css` — responsive modern dark-theme styling
- `script.js` — English/Arabic switch and mobile navigation
- `assets/portrait-illustration.jpeg` — supplied illustrated portrait
- `assets/Abdelkhalek-Mohamed-CV.pdf` — supplied CV for the View CV link

## Publish for free with GitHub Pages

1. Create or sign in to a GitHub account at https://github.com/.
2. Click **New repository**.
3. For the repository name, enter exactly: `YOUR-USERNAME.github.io`
   - Replace `YOUR-USERNAME` with your GitHub username.
   - Example: if your username is `abdelkhalekm`, the repository must be `abdelkhalekm.github.io`.
4. Set the repository visibility to **Public**.
5. Create the repository.
6. On the repository page, choose **Add file → Upload files**.
7. Open the downloaded ZIP on your computer, extract it, then upload the *contents* of the `abdelkhalek_portfolio` folder. Make sure `index.html`, `styles.css`, `script.js`, and the `assets` folder are at the repository's top level (do not upload only the ZIP).
8. Click **Commit changes**.
9. Open **Settings → Pages**.
10. Under **Build and deployment**, choose **Deploy from a branch**.
11. Select branch **main** and folder **/(root)**, then click **Save**.
12. Wait a few minutes. Your public website will be:
    `https://YOUR-USERNAME.github.io/`

## Important

- GitHub Pages is free for public repositories. No paid hosting or custom domain is required.
- Do not rename `index.html`, `styles.css`, `script.js`, or the `assets` folder unless you also update the references in the HTML.
- The contact details and experience are based on the supplied CV. Review them before publishing because the site makes your phone numbers and email publicly visible.
- The CV PDF is included as a public download. Remove it from `assets` and remove the CV buttons if you do not want the full CV downloadable.
- The site uses Google Fonts when a visitor has internet access; system fallback fonts are provided.
- To preview locally, open `index.html` in a browser.

## Updating the website

Edit the relevant text in `index.html`, save, then upload the changed file to the same GitHub repository and commit the change. GitHub Pages will publish the update automatically.
